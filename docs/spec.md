# ai_gamesについて

ai_gamesはちょっとした暇つぶしができるゲームを集めたゲームプラットフォームです。
ネイティブアプリではないのでダウンロードせずに気軽に遊べます。
全てのゲームはフロントエンドのみで遊ぶことができ、バックエンドでの処理やデータの保存は行いません。
ユーザーがTOPページでゲームを選択すると、当該のゲームページに遷移し、遊ぶことができる流れです。
PC/スマホの両方で遊べるようにレスポンシブデザインで実装するほか、スマホでは横画面でゲームを遊べるようにUIを組み上げます。


# 各ページの仕様

## TOPページ

URL: /

ユーザーがTOPページを開くと、ゲームの一覧が表示されます。
各ゲームはGameItemを使って表示します。（GameItemについては共通コンポーネントの欄を参照）
ゲーム名での検索およびカテゴリでの検索により、ゲームを絞り込むことができます。

## ゲームページ

URL: /game/{id}

ゲームページを開くと、GameFrameの中でゲームが始まります。
枠はYahooやDMMなどのプラットフォームで遊べたゲームと同じようなイメージです、横長で9/16の比率です。。
枠の下にはTOPに戻るAppButtonを設定します。ボタンを押すとゲームを終了するConfirmModalを表示し、「はい」を押すとTOPページに戻ります。「いいえ」を押すと確認アラートが消えて、ゲームの続きを遊べます。

## 利用規約

URL: /terms

利用規約を記載したページです。

## プライバシーポリシー

URL: /privacy_policy

プライバシーポリシーを記載したページです。


# ゲームの仕様

ゲームは以下のデータを持ちます。

id: ユニークキー
title: ゲーム名
image: 画像パス
categoryIds: カテゴリIDの配列


# カテゴリの仕様

TOPページでの検索でユーザーフレンドリーなUXを提供するため、それぞれのゲームにはカテゴリを設定します。
カテゴリは以下のデータを持ちます。

id: ユニークキー
categoryName: カテゴリ名


# 利用技術
以下の言語、技術を使用して実装します。
HTML / React.js / Next.js / TypeScript / SCSS / Jest


# 共通コンポーネント

## GameItem

TOPページなどに表示するゲーム画像とゲーム名の組み合わせ。
ゲーム画像の下にゲーム名が表示されている。
PCで５つ、スマホで２つ横に並べて表示できる大きさ。
クリックするとゲームページに遷移する。
ゲーム画像は横長の9/16の比率。
ゲーム名は2行まで表示でき、それ以上は見切れる。

## GameFrame

ゲームを表示する枠です。
横長の9/16の比率です。

## AppButton

ゲームページのTOPに戻るボタンなどに利用する共通のボタン。

## ConfirmModal

確認モーダルを表示し、「はい」「いいえ」ボタンを表示します。
ゲームを終了してTOPページに戻るボタンを押下した際などに表示します。

## AppHeader

共通のヘッダーです。
layoutファイルで使用する想定です。

## AppFooter

共通のフッターです。
layoutファイルで使用する想定です。

## FinishModal

ゲームオーバーになったときに表示されるモーダル。
ゲームのスコア、もう１度遊ぶボタン、SNSシェアボタン群を表示する。

## SocialButtons

SNSシェアボタン群のUI。
サービスやゲームのスコアをSNSで共有するためのボタン群。
