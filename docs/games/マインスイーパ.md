# マインスイーパ

## 基本情報

ID: 3
ゲーム名: マインスイーパ
カテゴリ: パズル

## 内容

シンプルなマインスイーパのゲームです。
かんたん、ふつう、むずかしいの３つの難易度で遊べます。
難易度が上がるごとに、全体のマスの数および爆弾の数が増加します。

## 操作

マスを選択
PC: クリック
SP: タップ

## 画面構成

### スタート画面
マインスイーパっぽい背景画像にスタートボタンを置きます。
スタートボタンを押すと、難易度の選択ボタンが表示されます。
難易度選択は横長のボタンを縦に並べて、上から、かんたん、ふつう、むずかしいの順で置きます。
それぞれのボタンの背景色は、かんたんは黄緑、ふつうは黄色、むずかしいは赤にしましょう。
難易度を選択したら、自動的にプレイ画面に移動します。

### プレイ画面
マインスイーパのUIと、爆弾の数、経過時間、スタート画面に戻るボタンを表示します。
爆弾の数と経過時間とスタート画面に戻るボタンは右上に表示します。
爆弾の数は、「爆弾の総数 - 設置した側の数 / 爆弾の総数」というフォーマットで表示します。例えば爆弾の総数が30個、設置した旗が10個であれば、「20 / 30」となります。
経過時間は「hh:mm:ss」のフォーマットで表示してください。
スタート画面に戻るボタンを押すと、本当にスタート画面に戻るか確認するモーダルが表示されます。モーダル上で「はい」を選ぶとスタート画面に戻ります。「いいえ」を選ぶとモーダルが消えて続きを遊べます。

ゲームが始まるとプレイヤーは最初に掘るマスを選択します。
最初に掘るマスを選択した時点で、そのマスに爆弾が来ないように爆弾を配置してください。
爆弾を配置したら、プレイヤーが選択したマスを掘って、ゲームがスタートします。
経過時間のカウントは、開け終わったタイミングとしてください。
それ以降は、プレイヤーはマスを選ぶと、「掘る」「旗を置く」「キャンセル」を選ぶUIが表示されます。旗は爆弾があると思った場所に置くもので、クリック/タップしやすい程度の大きさを保持しつつ、小さめにしたいです。
堀って数字が書かれたマスも、書かれた数字ぶんの旗を周りに立てた後であれば選択可能になります。この場合「掘る」「キャンセル」の２つだけ表示して、「旗を置く」は表示しないでください。

### 終了画面
クリアもしくは爆弾を開けてゲームオーバーになった際、自動的に終了画面に移動します。
UIは共通のものを使用します。
かかった時間がスコアとなります。
もう１度遊ぶボタンを押すと、難易度選択に戻ります。
