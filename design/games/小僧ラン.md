# 小僧ラン デザイン仕様（夕焼け下町）

ゲーム「小僧ラン 〜迫り来る母ちゃんの恐怖〜」のデザイン仕様です。ゲームの内容と操作は [小僧ラン.md](./小僧ラン.md) を正とし、この資料は見た目・演出・ゲームの手ざわりを定義します。プラットフォーム共通の部分（GameFrame、ResultModal、ShareButtons など）は [docs/design.md](../design.md) を見てください。

## 0. 参照モック

- **見た目と動きの正解: [temp/kozo-run/design.html](../../temp/kozo-run/design.html)**（ブラウザで直接開けます。実際に遊べます）
  - ゲームのルールと状態遷移: [temp/kozo-run/engine.js](../../temp/kozo-run/engine.js)
  - キャラクター・背景・障害物の描画: [temp/kozo-run/skin.js](../../temp/kozo-run/skin.js)（`SKIN`）
  - TOP の一覧（GameItem）用の画像: [temp/kozo-run/thumbnail.png](../../temp/kozo-run/thumbnail.png)（描画元は [thumbnail.html](../../temp/kozo-run/thumbnail.html)）
  - プラットフォームの外枠、ResultModal、ShareButtons: [temp/kozo-run/shell.css](../../temp/kozo-run/shell.css)
- URL の末尾に `#play` を付けるとプレイ中、`#over` を付けると終了モーダルの状態から始まります（左下の操作バーからも切り替えられます）
- 迷ったらモックの値を優先してください。この資料の数値はモックから抜き出したものです。
- モック固有で**実装しないもの**
  - 左下の操作バー、`#play` と `#over` の仕組み
  - ページの外枠（ヘッダー、見出し、EXIT ボタン）。本実装ではプラットフォームの GameFrame の中にゲームを置きます

### 構成

```
GameFrame（プラットフォーム共通・16:9）
└─ 小僧ラン（GameFrame の children）
   ├─ canvas            … 背景・キャラクター・障害物・吹き出し（論理解像度 960×540）
   ├─ 危険エフェクト    … 母ちゃんが迫ると左側が赤く光る（HTML）
   ├─ 距離表示（HUD）   … 右上（HTML）
   ├─ スタート画面      … タイトルとスタートボタン（HTML）
   └─ ResultModal       … 終了時（プラットフォーム共通コンポーネント）
```

- canvas は GameFrame いっぱいに広げ、内部は **論理解像度 960×540** で描画します。backing store は `devicePixelRatio`（上限2）倍にします
- HTML の UI（HUD、スタート画面）は、GameFrame の幅に比例させます。ゲームのルート要素に `container-type: size` を付け、寸法は `cqw`（GameFrame 幅の1%）で指定してください。スマホでも PC でも、同じ見た目の比率になります

## 2. 画面

### 2-1. スタート画面

背景では、デモとして小僧と母ちゃんが走っています（§5 デモ）。その上に、半透明のグラデーション `linear-gradient(rgba(255,180,90,.1), rgba(60,20,40,.45))` を重ねます。

中央に縦に並べ、全体を `translateY(-5cqw)` だけ上にずらします（下を走る小僧と母ちゃんに重ならないようにするため）。要素間の gap は .6cqw です。

| 要素 | 文言 | スタイル |
|---|---|---|
| バッジ | 母ちゃんから にげきれ！ | 背景 ink / 文字 yellow / Zen Maru Gothic 900 / 1.5cqw / padding .5cqw 1.8cqw / 角丸 99px |
| タイトル | 小僧ラン | Mochiy Pop One / 10cqw / line-height 1.1 / yellow / ふち `-webkit-text-stroke: 1cqw ink`（`paint-order: stroke fill`）/ 影 `.7cqw .7cqw 0 ink` / `rotate(-3deg)` |
| サブタイトル | 〜迫り来る母ちゃんの恐怖〜 | Mochiy Pop One / 2.2cqw / 白 / ふち .5cqw ink |
| スタートボタン | にげる！ | §2-4 ボタン。上余白 1.2cqw |
| 操作ヒント | スペースキー ／ 画面タップでジャンプ | Zen Maru Gothic 900 / 1.5cqw / 白 / `text-shadow: 0 0 .6cqw ink, 0 0 .3cqw ink` / 上余白 .8cqw |

- スタートボタンを押すか、スタート画面で Space キーを押すと、プレイ画面に移ってすぐにゲームが始まります

### 2-2. プレイ画面

- スタート画面の UI を消し、右上に距離表示（HUD）を出します
- 母ちゃんが近づくと、危険エフェクトと吹き出しが出ます（§5 演出）

#### 距離表示（HUD）

仕様書どおり、右上に置きます。

```
 ┌───────────┐  ← 背景 paper / 枠 .35cqw ink / 角丸 1.2cqw / 影 .5cqw .5cqw 0 ink
 │ 逃げた距離 │  ← Zen Maru Gothic 900 / 1.2cqw / ink
 │   323 m   │  ← 数字 Mochiy Pop One 3.8cqw red、「m」は .5em ink（左余白 .2em）
 └───────────┘     全体を rotate(2deg)
```

- 位置：上から 3cqw、右から 3cqw。padding は `.8cqw 1.6cqw 1cqw`。右揃え
- 数字は `toLocaleString()` で3桁区切りにします（例：1,234）
- **枠の幅は、桁数が変わったときだけ変わる**ようにします。数字の要素を `display: inline-block; text-align: right` にし、幅を次の式で固定してください

  ```scss
  // digits = 桁数、commas = カンマの数
  width: calc(var(--digits) * .68em + var(--commas) * .26em);
  ```

  Mochiy Pop One の数字の幅は 1文字あたり 0.661〜0.665em、カンマは 0.245em でした（実測）。少し余裕を持たせた値にしています
- 数字が変わったときだけ DOM を更新してください（毎フレーム書き換えない）
- スクリーンリーダーで毎フレーム読み上げられないよう、`aria-live` は付けません

### 2-3. 終了（つかまったとき）

1. 母ちゃんとの距離が 0 になった瞬間に、ゲームを止めます（画面は最後の場面のまま）
2. その場面のまま、母ちゃんの吹き出しを「つかまえた！」に変え、小僧の上に「ひぃ〜」と表示します
3. **650ms 後**に、プラットフォーム共通の **ResultModal** を開きます（[design.md §5 ResultModal](../design.md)）
   - `scoreLabel`：逃げた距離
   - `score`：逃げた距離（m、整数）／ `unit`：m
   - `shareText`：`小僧ランで母ちゃんから{score}m逃げた！ #小僧ラン #NEON_GAMES`
   - 「もう1度プレイする」で、スタート画面を挟まずにすぐ次のゲームを始めます

### 2-4. ボタン（スタートボタン）

ゲーム内の UI なので、プラットフォームの AppButton ではなく、このゲーム専用の見た目にします。

- 高さ 6.4cqw、padding `0 5cqw`、角丸 99px、背景 red、枠 `.35cqw solid ink`、Mochiy Pop One / 2.6cqw / 白
- 影 `0 .6cqw 0 ink`（下にずらした影で、押せそうな厚みを出します）
- hover と focus-visible：`translateY(-.2cqw)` と `filter: brightness(1.08)`
- focus-visible：`outline: .3cqw dashed #fff; outline-offset: .4cqw`
- active（押している間）：`translateY(.5cqw)`、影を `0 .1cqw 0 ink` に縮める
- transition：transform と box-shadow を .1s

## 3. 背景（canvas）

奥から順に描きます。地面の高さ（GROUND）は y = 452 です。スクロール量 `cam`（走った距離、px）に、層ごとの係数をかけて横にずらします（パララックス）。

| 層 | 係数 | 内容 |
|---|---|---|
| 空 | 0 | 縦グラデーション `#5B4B9A` → `#E8708A`（45%）→ `#FFB067`（80%）→ `#FFD98A`（地面） |
| 夕日 | 0 | 中心 (720, 250)、半径 70、`#FFF0C2` |
| カラス | 0.05 | 3羽。ink の線（太さ3）で「へ」の字を2つつなげる |
| 遠くの家並み | 0.15 | 幅 120 ごと。三角屋根の家のシルエット `#8A4E73`。高さはランダム（70〜130）。窓 `#FFD27A` を一部の家に灯す |
| 電柱と電線 | 0.5 | 間隔 380。電柱 `#4A2E3C`（幅 16）と腕木。電線は ink（太さ2）を2本、たるませる |
| ブロック塀 | 1.0 | 地面から高さ 120。`#C9B3A6`、目地 `rgba(43,27,36,.35)`（1段 20、ブロック幅 80、段ごとに半分ずらす）。上端に笠木 `#A88F84`（ink のふち取り） |
| 道路 | 1.0 | `#7A6670`。地面の線 ink（太さ4）。白線 `#F4E9D8`（長さ 70、間隔 140） |

- 家並みの高さなど「ランダム」の部分は、毎フレーム変わらないよう、位置（インデックス）から決まる疑似乱数を使ってください（モックの `rnd(i, seed)`）

## 4. キャラクターと障害物（canvas）

すべて **ink（`#2B1B24`）のふち取り（太さ3）＋フラットな塗り**で描きます。手足は、ink の太い線の上に、肌色の細い線を重ねて描きます（ふち取りに見えます）。モックでは canvas のパスで描いています。本実装で画像（スプライト）に置き換えてもかまいませんが、**当たり判定の大きさ（下表）は変えないでください**。

### 小僧

| 項目 | 値 |
|---|---|
| 当たり判定 | 48 × 72（x = 330 に固定。動くのは背景と障害物） |
| 見た目 | 坊主頭、白いランニングシャツ（胸に赤い線）、青い半ズボン（`#3D5BA9`）、肌 `#F6C9A0`、ほっぺ `#F28B82`、汗のしずく `#7CC6F2` |
| 走り | 手足を `sin(走った距離 × 0.09)` で振る |
| ジャンプ中 | 脚を曲げたポーズ |
| 障害物にぶつかって止まっている間 | 腕を前に突き出して押すポーズ。脚は時間で動かし続ける（足踏み） |
| つかまったとき | 頭の上に「ひぃ〜」（Mochiy Pop One / 26px / red） |

### 母ちゃん

| 項目 | 値 |
|---|---|
| 大きさ | 88 × 112（当たり判定はありません。小僧との距離だけで判定します） |
| 見た目 | パーマ頭（`#5E4458` の円を重ねる）、紫のワンピース（`#7D6BB5`）、ピンクのエプロン（`#FF9DB8`、白い水玉）、怒り眉、開いた口、頭の横に怒りマーク（red） |

| 障害物の通過 | 足元を障害物が通るときは、障害物の高さ＋26px だけ放物線を描いて跳び越える（演出のみ） |
| 吹き出し | 距離が近い（危険度 0.45 以上）ときに「まちなさーい！」、つかまえたときに「つかまえた！」。白地・ink のふち取り・角丸の吹き出しに、Mochiy Pop One / 22px / red |

## 5. ゲームの手ざわり（ルールと数値）

数値はプロトタイプで調整した暫定値です。**定数として1か所にまとめ、あとから調整しやすくしてください**。単位の「フレーム」は 60fps 換算です。実際のフレームレートに合わせて、経過時間で補正してください（モックは 1フレームあたり最大 2.5 倍まで補正）。

### 走りとスクロール

| 項目 | 値 |
|---|---|
| 距離の換算 | 40px = 1m |
| 走る速さ | 7px/フレームから始まり、1m 進むごとに +0.012、上限 13px/フレーム |
| 障害物の出現間隔 | 速さ × 42 を最低間隔とし、そこに 0〜420px のランダムを足す |
| 最初の障害物 | 開始から 700px 先 |

### ジャンプ

| 項目 | 値 |
|---|---|
| 初速 | −16.5px/フレーム（上向き） |
| 重力 | 0.85px/フレーム² |
| 条件 | 地面か障害物の上に立っているときだけ（空中で2段ジャンプはできない） |
| 操作 | PC：Space キー（押した瞬間）。スマホ：画面タップ（`pointerdown` の瞬間） |

- 入力の遅れを感じさせないよう、`click` ではなく、キーを押した瞬間と `pointerdown` で反応させてください
- プレイ中は Space キーでページがスクロールしないよう、`preventDefault` してください
- GameFrame には `touch-action: manipulation` を付けて、ダブルタップでの拡大を防いでください。テキスト選択も無効にします
- ボタンやリンクの上でのタップは、ジャンプにしません

### 障害物との当たり

- 小僧が障害物の**側面**にぶつかると、その間は先に進めません（スクロールが止まり、距離も増えません）
- 障害物の**上面**には着地できます。上を走り抜けて、端から落ちます
- 止まっている状態からジャンプして、障害物の上面より高くなれば、また進めます

### 母ちゃんとの距離（gap）

| 項目 | 値 |
|---|---|
| 最大距離 | 200px（スタート時もこの距離） |
| 止まっている間 | 3.2px/フレームずつ縮む（約1秒止まると、最大距離からつかまる） |
| 走れている間 | 0.35px/フレームずつ広がる（最大距離まで） |
| つかまる | 距離が 0 になったとき |

- 「走れている間は離れる」は、仕様書にないデザイン上の追加です（§7 未決事項）

### 演出

| 演出 | 条件 | 内容 |
|---|---|---|
| 危険エフェクト | 危険度 = 1 − 距離 ÷ 200 | GameFrame の左側に `radial-gradient(110% 120% at 0% 60%, rgba(232,71,59,.6), transparent 55%)` を重ねる。不透明度は `(危険度 − .55) × 2.2`（危険度 0.55 から出始める） |
| 母ちゃんの吹き出し | 危険度 0.45 以上 | 「まちなさーい！」 |
| デモ | スタート画面 | 小僧と母ちゃんが走り続け、小僧は障害物の手前で自動でジャンプする。母ちゃんとの距離は縮まない |

## 7. 実装メモ・未決事項

### 実装メモ

- **ConfirmModal との連携**：プレイ中にプラットフォームの ConfirmModal（EXIT や、ロゴのクリック）が開いたら、ゲームを一時停止してください。「いいえ」で閉じたら再開します。GameFrame から「モーダル表示中」を受け取れるようにしておく想定です（[design.md §5 ConfirmModal](../design.md)）
- **タブが非表示のとき**：`visibilitychange` でタブが隠れたら一時停止してください。戻ったときに、経過時間の補正で一気に進まないようにするためです
- **`prefers-reduced-motion`**：ゲームの動き自体は止めません。スタートボタンの押し込みなど、UI のトランジションだけを止めます
- **スコアの保存**：仕様書どおり、ベストスコアなどは保存しません
- **GameItem の画像**：[temp/kozo-run/thumbnail.png](../../temp/kozo-run/thumbnail.png)（1280×720、PNG）をゲームデータの `image` に使ってください。置き場所は、例えば `public/images/games/kozo-run.png` です。§8 も見てください

### 未決事項（PM確認中）

暫定の対応で実装を進めてください。決まったら、この資料を更新します。

| # | 内容 | 暫定の対応 |
|---|---|---|
| 1 | 母ちゃんとの距離のルール。仕様書は「ぶつかっている間は進めない」だけ。走れている間に距離が広がるか | 広がる（0.35px/フレーム）。広がらない設定にすると、一度ぶつかった分を取り返せず、かなり難しくなります |
| 2 | ShareButtons に Instagram 向けの「画像でシェア」を足すか | 今は入れない（[design.md §7](../design.md)） |
| 3 | ResultModal のスコアの上の見出し「逃げた距離」を残すか | 残す |
