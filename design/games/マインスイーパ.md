### 構成

```
GameFrame（プラットフォーム共通・16:9）
└─ マインスイーパ（GameFrame の children）
   ├─ 背景（土の地層）
   ├─ 上部         … 左：難易度、中央：ヒント、右：爆弾の数・経過時間・スタート画面に戻るボタン
   ├─ 盤面         … マス（ボタン）を格子に並べる
   ├─ 選択メニュー … 掘る／旗を置く／キャンセル（マスの上か下に出る吹き出し）
   ├─ 告知         … CLEAR! ／ BOOM!
   ├─ 確認モーダル … スタート画面に戻りますか？
   ├─ スタート画面 … タイトル → 難易度選択
   └─ ResultModal（プラットフォーム共通コンポーネント）
```

- **寸法は GameFrame の幅に比例**させます。ゲームのルート要素に `container-type: size` を付け、寸法は `cqw`（GameFrame 幅の1%）で指定してください。GameFrame の高さは 56.25cqw です
- 小さい画面でも読めて押せるよう、文字とボタンには `max(11px, 1.5cqw)` のように最小値を付けています（値は各表）
- 画面の状態は `start`（スタート画面）／`ready`（最初の1マスを待っている）／`play`／`over`（終了演出〜ResultModal）です。モックではルート要素の `data-state` で切り替えています

## 1. 世界観とトークン

発掘現場です。土のブロックを掘ると砂地と数字が出て、爆弾がありそうな場所に測量用の赤い旗を立てます。太い縁取りと、下にずらした影で、押せる感触を出します。

### カラー

| トークン | 値 | 用途 |
|---|---|---|
| `ink` | `#2A1C10` | 縁取り、影、濃い文字 |
| `dirt` | `#B07A48` | 掘っていないマス |
| `sand` | `#F1DEB2` | 掘ったマス |
| `cream` | `#FFF4DA` | メニュー・確認モーダルの背景、明るい文字 |

## 3. 画面と流れ

### 3-1. 全体の流れ

```
スタート画面 ─「掘りはじめる」▶ 難易度選択 ─ 難易度 ▶ プレイ（最初の1マス）
                                    ▲                        │
                                    │                        ▼
                                    │                  プレイ（2手目から：メニューで操作）
                                    │                        │
                         「もう1度プレイする」          クリア／爆発 → 告知 → ResultModal
                                    └────────────────────────┘
   どの画面からも「⌂」→ 確認モーダル「はい」でスタート画面へ
```

### 3-2. スタート画面

**背景**：マインスイーパの盤面（22×12 マス、マス 4.8cqw、間隔 .2cqw）を `rotate(-8deg) scale(1.15)` で斜めに敷きます。中央が開いていて、数字と旗が見える模様です。その上に、中央が少し明るい暗幕（`radial-gradient(55% 65% at 50% 50%, rgba(40,25,12,.55), rgba(40,25,12,.88))`）を重ねます。模様は表示のたびにランダムでかまいません。

**工事テープ**：上下に、黄色と黒の斜めじまの帯（高さ 2.6cqw、`repeating-linear-gradient(-45deg, yellow 0 2cqw, #1E1612 2cqw 4cqw)`）を置きます。上は top 2cqw・`rotate(-1.5deg)`、下は bottom 2cqw・`rotate(1.5deg)`。左右は GameFrame から 2cqw はみ出させます。

中央に縦に並べます（gap 1cqw）。

| 要素 | 文言 | スタイル |
|---|---|---|
| バッジ | 工事中・爆弾に注意 | 背景 `#1E1612`、文字 yellow、Zen Maru Gothic 900 / 1.5cqw、padding `.4cqw 1.6cqw`、角丸 99px |
| タイトル | マインスイーパ | Dela Gothic One / 8cqw / line-height 1.15 / yellow。縁取り `-webkit-text-stroke: 1cqw ink`（`paint-order: stroke fill`）、影 `.7cqw .7cqw 0 ink` |
| サブタイトル | 爆弾を避けて、ぜんぶ掘りあてろ！ | Zen Maru Gothic 900 / 1.9cqw / cream、`text-shadow: 0 .2cqw .4cqw rgba(0,0,0,.6)` |
| スタートボタン | 掘りはじめる | §4-6 スタートボタン。上余白 1.6cqw |

### 3-3. 難易度選択

仕様書どおり、スタートボタンを押すと、タイトルの代わりに難易度の選択を出します（背景と工事テープはそのまま）。

- 見出し「難易度をえらんでください」（Zen Maru Gothic 900 / 2.2cqw / cream、影付き）
- その下に、横長のボタンを縦に並べます（gap 1.4cqw）。**上から かんたん（黄緑）、ふつう（黄色）、むずかしい（赤）**
  - 幅 36cqw、高さ 7cqw（最小 44px）、padding `0 2.6cqw`、枠 `.3cqw solid ink`、角丸 .8cqw、影 `0 .5cqw 0 ink`
  - 左に難易度名（Dela Gothic One / 2.6cqw）、右に盤面の情報「10×6・爆弾 8」（Zen Maru Gothic 900 / `max(10px, 1.3cqw)`）
  - 文字色：かんたんとふつうは ink、むずかしいは白
  - hover / focus-visible で `translateY(-.3cqw)` と `brightness(1.08)`、押している間は `translateY(.4cqw)` で影を縮める。focus-visible は `.3cqw dashed #fff` の outline
- 表示したら、かんたんのボタンにフォーカスを移します
- ボタンを押すと、すぐにプレイ画面に移ります（仕様書どおり）

### 3-4. プレイ画面（最初の1マス）

1. 盤面はすべて掘っていない状態で出します。上部中央にヒント「最初に掘るマスを選んでください」を出します
2. 最初に選んだマスは、**メニューを出さずにすぐ掘ります**
3. 掘る直前に爆弾を置きます。**選んだマスとその周り8マスには置きません**（§5。仕様書は「そのマスに爆弾が来ないように」。周りも空けると、最初に必ず広く開くので遊びやすくなります）
4. マスが開く演出（§3-7）が終わってから、経過時間を数え始めます（仕様書どおり）
5. ヒントを消します

### 3-5. プレイ画面（2手目から）：選択メニュー

マスを選ぶ（クリック／タップ）と、そのマスの上に吹き出しのメニューを出します（仕様書どおり）。

| 選んだマス | メニュー（左から） |
|---|---|
| 掘っていないマス | 掘る ／ 旗を置く ／ キャンセル |
| 旗を立てたマス | 旗を外す ／ キャンセル |
| 数字のマス（条件を満たしたとき） | 掘る ／ キャンセル |

- **旗を外す**は、仕様書にない追加です。旗を立てたマスの扱いが決まっていなかったため、ここで外せるようにしました（§7）
- **数字のマス**は、周りに立てた旗の数が数字と同じで、まだ掘っていないマスが周りに残っているときだけ選べます（仕様書どおり。「旗を置く」は出しません）。「掘る」で、旗のない周りのマスをまとめて掘ります
  - 選んだとき、掘られる周りのマスを黄色の枠（`inset 0 0 0 .25cqw yellow`）で示します
  - 条件を満たしていない数字のマスや、0（空き）のマスを押したときは、メニューを出さず、マスを小さく横に揺らします（.25s）
- 選んだマスは `scale(1.08)` で手前に出し、黄色の枠（`0 0 0 .3cqw yellow`）と影を付けます
- メニューを開いたまま別のマスを押すと、そのマスのメニューに切り替えます。同じマス、盤面の外、Esc キー、「キャンセル」で閉じます
- 開いたら、メニューの最初のボタンにフォーカスを移します。閉じたら、選んでいたマスにフォーカスを戻します

**メニューの位置**

- 選んだマスの真上（8px 上）に出し、下向きの三角でマスを指します
- 数字のマスのときは、掘られる周りの3×3を隠さないよう、その範囲の上に出します
- 上に出すと上部（爆弾の数・時間）に重なる場合は、マスの下に出し、三角を上向きにします
- 左右は GameFrame の内側（端から 8px）に収め、三角だけをマスの真上（真下）に合わせます

**メニューの見た目**

- 背景 cream、枠 `.3cqw solid ink`、角丸 .8cqw、影 `.4cqw .4cqw 0 ink`、padding .7cqw、ボタンの間隔 .6cqw
- ボタン：高さ 4.2cqw（最小 32px）、最小幅 4.8cqw、padding `0 1.5cqw`、Zen Maru Gothic 900 / `max(12px, 1.5cqw)`、枠 `.25cqw solid ink`、角丸 .5cqw、影 `0 .3cqw 0 ink`
  - 掘る：背景 yellow ／ 旗を置く・旗を外す：背景 red、白文字 ／ キャンセル：背景白
  - hover / focus-visible で `translateY(-.15cqw)`、押している間は `translateY(.25cqw)` で影を縮める
- 出るとき：`translateY(.6cqw)`・不透明度0 から .15s

### 3-6. 上部の表示

| 位置 | 要素 | 内容 |
|---|---|---|
| 左 | 難易度ラベル | 「ふつう」。背景 yellow、文字 ink、枠 `.25cqw solid ink`、角丸 .4cqw、影 `.3cqw .3cqw 0 ink`、`max(11px, 1.6cqw)` |
| 中央 | ヒント | 最初の1マスのときだけ「最初に掘るマスを選んでください」。cream、`max(11px, 1.5cqw)`、影付き |
| 右 | 爆弾の数 | 爆弾のアイコン＋「**18 / 18**」 |
| 右 | 経過時間 | 時計のアイコン＋「**00:01:23**」 |
| 右端 | スタート画面に戻るボタン | 家のアイコン（§3-9） |

- 爆弾の数と経過時間の箱：高さ 4cqw（最小 26px）、padding `0 1.2cqw`、背景 `#2E1F12`、枠 `.2cqw solid #120A04`、内側に `.2cqw #6B4A2C` の線、角丸 .5cqw。数字は Dela Gothic One / `max(12px, 1.9cqw)` / `#FFE7A8`（背景に対して 13:1）。アイコンは `max(14px, 2cqw)` 四方、同じ色
- 3つの間隔は 1cqw
- **爆弾の数**は「爆弾の総数 − 立てた旗の数 / 爆弾の総数」です（仕様書どおり）。旗を立てすぎてマイナスになったら、そのまま「−1 / 18」と出し、数字を `#FF8A7A` にします
- **経過時間**は「hh:mm:ss」です（仕様書どおり）。最初の1マスが開き終わるまでは「00:00:00」のまま

### 3-7. マスが開く演出

- 0（周りに爆弾がない）のマスを掘ると、周りのマスへ連鎖して開きます。**選んだマスからの距離（何手先か）× 28ms** ずつ遅らせて開き、波のように広がって見せます
- 1マスが開く動き：`scale(.82)`・明るさ1.8倍から、.18s で元に戻す
- すべて開き終わるまで（最後のマスの遅れ ＋ .18s）は、次の操作を受け付けません
- 旗を立てたとき：旗が上から落ちてくるように出す（`translateY(-40%) scale(.4)`・不透明度0 から .3s、少し跳ねる）

### 3-8. 終了

**クリア**（爆弾以外のマスをすべて掘ったとき）

1. 時間を止めます
2. 旗を立てていない爆弾のマスに、自動で旗を立てます（爆弾の数は「0 / 18」になります）
3. 盤面の枠を yellow にします
4. 0.5秒後、告知「CLEAR!」（yellow）を **1.3秒** 出します
5. ResultModal を開きます

**ゲームオーバー**（爆弾を掘ったとき）

1. 時間を止めます。掘った爆弾のマスを red にします
2. 盤面を揺らします（.45s、左右と上下に 0.3〜0.6cqw）
3. 0.45秒後、残りの爆弾（旗を立てていないもの）を、40ms ずつずらして表示します（`scale(.3)` から .3s、少し跳ねる）
4. 爆弾ではない場所に立てていた旗には、赤い「×」を重ねます
5. 0.4秒後、告知「BOOM!」（red）を **1.3秒** 出します
6. ResultModal を開きます

**告知**：Dela Gothic One / 7cqw、縁取り `.9cqw ink`、影 `.6cqw .6cqw 0 ink`。GameFrame の中央に、`scale(.5)`・不透明度0 から .35s で少し跳ねて出します。押せません（`pointer-events: none`）

**ResultModal**（[design.md §5 ResultModal](../design.md)）

| | クリア | ゲームオーバー |
|---|---|---|
| `scoreLabel` | クリアタイム（ふつう） | ゲームオーバー（ふつう） |
| スコア | かかった時間「00:01:23」 | 爆発までの時間「00:00:41」 |
| `unit` | なし | なし |
| `shareText` | `マインスイーパ（ふつう）を 00:01:23 でクリア！ #NEON_GAMES` | `マインスイーパ（ふつう）で 00:00:41 粘ったけど爆発…！ #NEON_GAMES` |

- **共通の ResultModal は、今のところスコアを数値（`score: number`）で受け取り、3桁区切りで表示します。** 時間「00:01:23」はそのまま渡せないので、スコアの表示を文字列で渡せるようにする（例：`displayScore?: string` を足す）など、共通部品の調整が必要です。調整方法はエンジニアの判断でかまいません。数値としてのスコアが必要なら、秒数（83）です
- 「もう1度プレイする」を押すと、**難易度選択**に戻ります（仕様書どおり）

### 3-9. スタート画面に戻る（確認モーダル）

右上の家のボタンを押すと、確認モーダルを出します（仕様書どおり）。

- **家のボタン**：4cqw 四方（最小 30px）、背景 cream、枠 `.25cqw solid ink`、角丸 .5cqw、影 `0 .3cqw 0 ink`、アイコンは ink で 55% の大きさ。hover / focus-visible で背景 yellow・`translateY(-.15cqw)`、押している間は `translateY(.25cqw)`。`aria-label`・`title` は「スタート画面に戻る」
- **確認モーダル**：GameFrame の上に重ねます。背景 `rgba(30,18,8,.55)`
  - パネル：幅 `max(40cqw, min(330px, 92%))`、padding `2.6cqw 2.6cqw 2.2cqw`、背景 cream、枠 `.35cqw solid ink`、角丸 1cqw、影 `.6cqw .6cqw 0 ink`、中央揃え。出るとき `translateY(.6cqw)`・不透明度0 から .18s
  - 見出し「スタート画面に戻りますか？」（Dela Gothic One / `max(14px, 2.2cqw)` / ink）
  - 本文「このゲームの盤面と時間は消えます。」（Zen Maru Gothic / `max(11px, 1.4cqw)` / `#6B5238`）
  - ボタン2つを等幅で横並び（gap 1.2cqw、上余白 1cqw）。**左「いいえ」（白）、右「はい」（red、白文字）**。高さ 5cqw（最小 36px）、`max(13px, 1.8cqw)`、枠 `.3cqw solid ink`、角丸 .6cqw、影 `0 .4cqw 0 ink`
- **挙動**
  - 「はい」：スタート画面（タイトル）に戻ります。ゲームは破棄します
  - 「いいえ」・Esc キー：モーダルを閉じて続きを遊べます。家のボタンにフォーカスを戻します
  - **開いている間は経過時間を止め**、閉じたら止めていた分を差し引いて再開します。スコアが時間なので、確認しているあいだにスコアが悪くならないようにするためです（デザインで追加。§7）
  - 開いたら「いいえ」にフォーカスします（安全側）。`role="dialog" aria-modal="true" aria-labelledby`（見出し）を付け、フォーカスをモーダル内で循環させます
  - 仕様書どおり、掘る前でも確認を出します
  - 終了の演出中に「はい」で戻った場合、そのゲームの告知や ResultModal は出しません

## 5. ルールと数値

数値は定数として1か所にまとめ、あとから調整しやすくしてください。

| 項目 | 値 | 根拠 |
|---|---|---|
| かんたん | 10列 × 6行、爆弾 8個 | **仮**（§7-1） |
| ふつう | 14列 × 8行、爆弾 18個 | **仮**（§7-1） |
| むずかしい | 18列 × 10行、爆弾 35個 | **仮**（§7-1） |
| 最初の1マスで爆弾を置かない範囲 | 選んだマスと周り8マス | **仮**（§7-2）。仕様書は「そのマス」 |
| 経過時間を数え始める | 最初の1マスが開き終わったとき | 仕様書 |
| 確認モーダル表示中の経過時間 | 止める | **デザインで追加**（§7-3） |
| 数字のマスで周りを掘れる条件 | 周りの旗の数 ＝ 数字、かつ未開封のマスが周りに残っている | 仕様書 |
| 旗を間違えた場所に立てて数字のマスを掘った場合 | そのまま掘る（爆弾があればゲームオーバー） | 一般的なルール |
| 盤面の比率 | どの難易度も横長（16:9 の GameFrame に合わせる） | デザイン |

- 盤面の比率は、GameFrame（16:9）に合わせて横長にしています。難易度を上げるほど、マスの数と爆弾の割合（13% → 16% → 19%）が上がります

## 7. 実装メモ・未決事項

### 実装メモ

- **ResultModal の調整**：時間「hh:mm:ss」をスコアとして表示できるようにしてください（§3-8）
- **ConfirmModal との連携**：プラットフォームの ConfirmModal（EXIT、ロゴのクリック）が開いている間も、経過時間を止めてください。このゲームの確認モーダルと同じ扱いです
- **タブが非表示のとき**：経過時間は実時間で数え、タブを隠している間も止めません（一般的なマインスイーパと同じ）。`setInterval` は非表示のタブで間引かれるので、表示は「開始時刻からの差」で計算してください（モックと同じ）
- **`prefers-reduced-motion`**：開く波・揺れ・跳ねる動きを止めてください。待ち時間はそのままにして、結果の区切りがわかるようにします
- **スコアの保存**：仕様書どおり、ベストタイムなどは保存しません
- **GameItem の画像**：[public/images/games/minesweeper.png](../../public/images/games/minesweeper.png)（1280×720、PNG）をゲームデータの `image` に使ってください（`/images/games/minesweeper.png`）。§8 も見てください

### 未決事項（PM確認中）

暫定の対応で実装を進めてください。決まったら、この資料を更新します。

| # | 内容 | 暫定の対応 |
|---|---|---|
| 1 | 盤面の大きさと爆弾の数 | かんたん 10×6・8個、ふつう 14×8・18個、むずかしい 18×10・35個 |
| 2 | 最初の1マスで爆弾を置かない範囲 | 選んだマスと周り8マス |
| 3 | 確認モーダルを開いている間、経過時間を止めるか | 止める |
| 4 | ゲームオーバーのときのスコア | 爆発までの時間を出し、見出しを「ゲームオーバー（{難易度}）」にする |
| 5 | 旗を立てたマスを選んだとき | 「旗を外す」「キャンセル」を出す |
