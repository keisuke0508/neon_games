# 1vs1 ポーカー デザイン仕様（ネオン・カジノ）

ゲーム「1vs1 ポーカー」のデザイン仕様です。ゲームの内容と操作は [docs/games/ポーカー.md](../../docs/games/ポーカー.md) を正とし、この資料は見た目・演出・画面の流れ・仮のルールの数値を定義します。プラットフォーム共通の部分（GameFrame、ResultModal、ShareButtons など）は [design/design.md](../design.md) を見てください。

### 構成

```
GameFrame（プラットフォーム共通・16:9）
└─ 1vs1 ポーカー（GameFrame の children）
   ├─ テーブル（背景）
   ├─ 上部       … 左：回数表示（ROUND 1/10）、右：ルールボタン
   ├─ CPU の席   … 上。手札5枚（裏向き）＋情報欄（名前・親・コイン・役）＋吹き出し
   ├─ 中央       … POT（賭けられたコインの合計）＋メッセージ
   ├─ あなたの席 … 下。情報欄＋手札5枚（表向き）
   ├─ 操作ボタン … 一番下
   ├─ 賭け金パネル（電卓）
   ├─ 告知（親決め・フェーズ・勝敗）
   ├─ スタート画面
   ├─ ルール説明モーダル
   └─ ResultModal（プラットフォーム共通コンポーネント）
```

- **寸法は GameFrame の幅に比例**させます。ゲームのルート要素に `container-type: size` を付け、寸法は `cqw`（GameFrame 幅の1%）で指定してください。GameFrame の高さは 56.25cqw です
- 小さい画面でも読めるよう、文字やボタンには `max(11px, 1.5cqw)` のように最小値を付けています（値は §3 と §4 の各表）
- 画面の切り替えは、状態（`start` / `play` / `exchange` / `showdown` / `over`）で管理する想定です。モックではルート要素の `data-state` で切り替えています

## 3. 画面と流れ

### 3-1. 全体の流れ

```
スタート画面 ─▶ 親決め（1回戦目だけ） ─▶ ┌─ 1回戦 ─────────────────────────────┐
                                           │ 参加費 → 配る → [BET] 1回目のベット   │
                                           │ → [CARD CHANGE] 交換 → [BET] 2回目のベット │
                                           │ → [SHOWDOWN] 勝負 → 決着               │
                                           │ （どちらかが降りたら、そこで決着）      │
                                           └────────────────────────────┬──────┘
                                                                        ▼
                              「次のゲームへ ▶」で次の回戦（親は交代）。10回戦が終わったら自動で結果へ
                                                                        ▼
                                                        最終結果の告知 → ResultModal
```

### 3-2. スタート画面

テーブルと伏せたカード（両者5枚ずつ）の上に、半透明の幕（`rgba(7,7,15,.55)` ＋ `blur(2px)`）を重ね、中央に縦に並べます（gap 1cqw）。右上のルールボタンは、スタート画面でも押せます（仕様書どおり）。回数表示と中央（POT）は隠します。

| 要素 | 文言 | スタイル |
|---|---|---|
| キッカー | NEON CASINO | Orbitron 600 / 1.5cqw / `letter-spacing: .5em` / yellow / 点滅（1.2s） |
| タイトル | 1vs1 **POKER** | Orbitron 800 / 8cqw / line-height 1 / `letter-spacing: .06em`。「1vs1」は白＋水色の光、「POKER」はピンク＋ピンクの光（`0 0 1cqw`, `0 0 3cqw`） |
| サブタイトル | CPU と10回戦。コインを増やせ！ | M PLUS 1p 800 / 1.8cqw |
| スタートボタン | START | 主ボタン（§4-6）。高さ 6.2cqw、padding 0 5cqw、Orbitron / 2.4cqw / `letter-spacing: .24em`、上余白 1.6cqw |
| 注記 | PCはクリックとキーボード、スマホはタップで遊べます | `max(10px, 1.2cqw)` / muted |

### 3-3. 親決め（1回戦目だけ）

仕様書どおり、親はランダムで決めます。

1. メッセージ「親を決めています…」
2. 「親」バッジが、あなたと CPU の情報欄の間を交互に移ります。12〜13回移り、だんだん遅くします（間隔 `70 + i² × 2.2` ms。i は0から数えた回数）
3. 止まった側が親です。告知「あなたが親」または「CPUが親」（小さく「親が先に賭けます」）を **1.2秒** 出します

2回戦目からは、親を毎回交代し、回の始めに告知「ROUND n」（小さく「あなたが親」「CPUが親」）を **1.0秒** 出します。

### 3-4. 参加費と配る

1. 両者から参加費（§5）を POT に移し、メッセージ「参加費 100コインずつ」
2. 5枚ずつ配ります。カードは上から落ちてくるように出します（`translateY(-1.6em) rotate(-10deg)`・不透明度0 から、.38s、`cubic-bezier(.2,.8,.3,1)`）。1枚ごとに 90ms ずらします
3. CPU のカードは裏向き、あなたのカードは表向きです。配り終えたら（0.9秒）、あなたの情報欄に、今の役名を表示します

### 3-5. フェーズの告知

フェーズが変わるたびに、親決めと同じ告知の帯を **0.95秒** 出します。どこを操作する段階かを、はっきり伝えるためです。

| タイミング | 大きな文字 | 小さな文字 |
|---|---|---|
| 配り終えたあと | BET | 1回目のベット |
| 交換の前 | CARD CHANGE | カードの交換 |
| 交換のあと | BET | 2回目のベット |
| 勝負の前 | SHOWDOWN | 手札を公開 |

- どちらかが降りた場合は、そこで決着するので、以降の告知は出しません
- 告知の見た目は §4-7 です

### 3-6. ベット

親が先に行動します（仕様書どおり）。番の人は、状況に応じて次から選びます。

| 状況 | 選べる操作（左から） |
|---|---|
| まだ誰も賭けていない（自分が親で最初の番） | **電卓が最初から開く**（下記） |
| まだ誰も賭けていない（相手がチェックした後） | 「チェック」「ベット…」 |
| 相手が賭けた | 「フォールド」（危険ボタン）「コール **500**」（主ボタン、金額は黄色）「レイズ…」 |

- 「ベット…」「レイズ…」を押すと、賭け金パネル（電卓）が開きます（§4-5）
- メッセージは状況に合わせて変えます：「あなたは親です。ベット額を決めてください」（1回目の親）／「ベット額を決めるか、チェックしてください」（2回目の親）／「チェックか、ベットか」／「CPU のベットに どうする？」

#### 自分が親のとき（電卓を最初から開く）

自分が親で、最初に賭ける番になったら、「ベット…」を押さなくても電卓を最初から開いておきます。

| 場面 | 電卓の左下のボタン |
|---|---|
| 1回目のベット | なし（親は必ず賭けるため）。「ベット ○○」ボタンを横いっぱいにする |
| 2回目のベット | 「チェック」。押すと電卓を閉じて、そのままチェックする |

- このとき Esc キーでは電卓を閉じません（閉じても、賭けるための操作は「ベット…」だけになり、二度手間のため）

#### CPU の番

1. メッセージ「CPU 考え中…」、CPU の吹き出しに「…」を出し、**0.7〜1.2秒**（ランダム）待ちます
2. CPU の行動を、吹き出し（例「ベット 500」「コール」「チェック」「フォールド」）と、メッセージ（例「CPUはベット（500）」）で知らせます
3. **0.6秒** 待ってから、次の人の番に進みます

### 3-7. カードの交換

1. メッセージ「交換するカードを選んでください」
2. あなたのカードを押す（クリック／タップ）たびに、選択と解除を切り替えます
   - **選んだカード**：`translateY(-.18em)`（カード幅の18%）持ち上げ、ピンクの線（`.035em solid magenta`）で囲み、ピンクの光（`0 0 .12em rgba(255,43,214,.9), inset 0 0 .08em rgba(255,43,214,.5)`）を付けます。文字の札などは付けません
   - 選んでいないカードは、hover で少しだけ持ち上げます（`-.06em`）
3. 操作ボタンは「交換しない」と「交換する」の2つ。「交換する」は、1枚以上選ぶまで押せません。選ぶと「**2枚** 交換する」のように枚数を出します
4. 交換するカードは、下に沈みながら消え（.25s）、新しいカードが配られます（§3-4 と同じ動き）。メッセージ「2枚 交換しました」／「交換しませんでした」。役名を更新します
5. **0.7秒** 後、CPU が交換します。同じ動きで CPU のカードを入れ替え、吹き出し「3枚 交換」／「交換しない」と、メッセージ「CPU は 3枚 交換しました」を出し、**0.9秒** 待ちます

### 3-8. 勝負（ショーダウン）

1. メッセージ「ショーダウン！」
2. CPU のカードを、左から 120ms ずつずらして裏返します（`rotateY` で .45s）
3. 0.9秒後、CPU の情報欄に役名を出し、さらに 0.5秒後に決着（§3-9）

### 3-9. 決着

| 結果 | 告知（1.3秒） | メッセージ |
|---|---|---|
| あなたの勝ち | WIN!（小さく「+1,200」）／黄色 | 「ストレート で あなたの勝ち！」 |
| CPU の勝ち | LOSE…（小さく「CPU +1,200」）／ピンク | 「スリーカード で CPU の勝ち」 |
| 引き分け | DRAW（小さく「POT を半分ずつ」） | 「同じ強さで引き分け」 |
| 相手が降りた | 勝った側の告知 | 「CPU が降りたので あなたの勝ち！」など |

- POT を勝った側に移し、コインの数字を **0.5秒** かけて増やします（POT は 0.4秒で 0 へ）。動きは `1 − (1 − p)³`（最後にゆっくり）
- 勝った側の情報欄を、黄色の枠と光（`0 0 2cqw rgba(255,230,0,.5)`）で強調します
- 引き分けは POT を半分ずつ分けます（奇数枚の端数は CPU 側）
- 降りた場合、CPU のカードは表にしません

### 3-10. 次のゲームへ／結果

- **1〜9回戦**：操作ボタンに「次のゲームへ ▶」（主ボタン）を出します。押すか、**4秒** たつと次の回戦に進みます
- **10回戦目、またはコインがなくなって続けられないとき**：ボタンは出さずに **1.2秒** 待ち、自動で最終結果へ進みます
- 最終結果の告知を **1.8秒** 出します

| 結果 | 告知 | 小さな文字 |
|---|---|---|
| あなたのコインが多い | YOU WIN!（黄色） | 「6,100 vs 3,900」 |
| CPU のコインが多い | YOU LOSE…（ピンク） | 同上 |
| 同じ | DRAW | 同上 |

- そのあと、プラットフォーム共通の **ResultModal** を開きます（[design.md §5 ResultModal](../design.md)）
  - `scoreLabel`：最終コイン
  - `score`：あなたの最終コイン数 ／ `unit`：枚
  - `shareText`：`1vs1 ポーカーでコインを{score}枚にした！ #NEON_GAMES`
  - 「もう1度プレイする」で、スタート画面を挟まずに、すぐ親決めから始めます

### 3-11. ルール説明モーダル

仕様書どおり、スタート画面とプレイ画面の右上のボタン「？ ルール」で開きます。

- GameFrame の上に重ねます。背景 `rgba(5,3,14,.7)` ＋ `blur(2px)`
- パネル：幅 76cqw・高さ 50cqw、背景 `rgba(16,17,30,.98)`、枠 `2px solid magenta`、角丸 1.6cqw、`box-shadow: 0 0 3cqw rgba(255,43,214,.4)`
- 上部：見出し「ルール説明」（2.2cqw）と、右に × ボタン（4cqw の円、最小 30px）。下に区切り線
- 本文は縦にスクロールします（`overscroll-behavior: contain`）。本文の文字は選択できるようにします
  1. **あそびかた**（見出しは水色 1.7cqw、強調語は黄色）
     - CPU と1対1で、10回戦のポーカーで勝負します。お互い 5,000コインから始まります
     - 毎回、参加費として 100コインを出し、5枚ずつカードが配られます
     - 親が先に賭けます。相手は コール（同じ額を賭ける）、レイズ（上乗せする）、フォールド（降りる）から選びます
     - いらないカードを選んで 交換できます（0〜5枚）。そのあと、もう一度賭けます
     - 最後に手札を見せ合い、強い役の人が賭けたコイン（POT）をすべてもらいます。降りた人は、それまでに賭けたコインを失います
     - ジョーカーは2枚入っていて、どのカードの代わりにもなります
     - 10回戦が終わったときのコインの枚数が、あなたのスコアです
  2. **役の一覧（強い順）**：§5 の役の表を、強い順に1行ずつ。左から「順位（Orbitron、ピンク）」「役名＋説明（小さく、不透明度 .75）」「見本のカード5枚（幅 3cqw）」。行の背景は surface-2、角丸 .8cqw
- × ボタン、または Esc キーで閉じ、開く前の要素にフォーカスを戻します。開いたら × ボタンにフォーカスします
- `role="dialog" aria-modal="true" aria-labelledby`（見出しを指す）を付けます
- ゲームはターン制なので、開いている間も状態は進みません（CPU の考え中だけは進みます。§7）

## 4. 部品

### 4-1. カード

縦横比 5:7。カードの幅を `1em` とし、中の要素は `em` で指定します（CPU は `font-size: 6.2cqw`、あなたは `9.4cqw`、ルール説明の見本は `3cqw`）。

```
┌──────┐
│A     │ ← 数字（Orbitron 800 / .24em）。その下にマーク（数字の .8倍）
│♠     │    左上 .06em / .08em
│  ♠   │ ← 中央に大きなマーク（.5em）
│      │
└──────┘    角丸 .08em
```

| 種類 | 色 | 枠 | 光 |
|---|---|---|---|
| ♠ ♣ | cyan | `.03em solid rgba(0,240,255,.55)` | `text-shadow: 0 0 .08em rgba(0,240,255,.8)` |
| ♥ ♦ | magenta | `.03em solid rgba(255,43,214,.55)` | `text-shadow: 0 0 .08em rgba(255,43,214,.8)` |

### 役（強い順）

| 順位 | 役 | 説明 | 見本 |
|---|---|---|---|
| 1 | ファイブカード | 同じ数字が4枚＋ジョーカー | 9 9 9 9 JK |
| 2 | ロイヤルストレートフラッシュ | 同じマークの 10・J・Q・K・A | ♠10 ♠J ♠Q ♠K ♠A |
| 3 | ストレートフラッシュ | 同じマークで数字が5つ連続 | ♥5〜♥9 |
| 4 | フォーカード | 同じ数字が4枚 | 7 7 7 7 K |
| 5 | フルハウス | スリーカード＋ワンペア | Q Q Q 4 4 |
| 6 | フラッシュ | 同じマークが5枚 | ♦2 ♦6 ♦9 ♦J ♦K |
| 7 | ストレート | 数字が5つ連続（マークはばらばら） | 8 9 10 J Q |
| 8 | スリーカード | 同じ数字が3枚 | 5 5 5 K 2 |
| 9 | ツーペア | ペアが2組 | J J 3 3 9 |
| 10 | ワンペア | 同じ数字が2枚 | 10 10 A 7 4 |
| 11 | ノーペア | 役なし。一番強いカードで比べます | A J 8 5 3 |

- 数字の強さは A > K > Q > J > 10 > … > 2。ストレートでは A を一番下にも使えます（A-2-3-4-5。ストレートの中で一番弱い）。K-A-2 のようには一周しません
- マークに強弱はありません
- 同じ役どうしは、役を作っている数字の強さ、次に残りのカードの強さで比べます。完全に同じなら引き分けです
- モックの判定（`evalHand`）は、ジョーカーを含む19通りの手札で正しさを確認しています。ジョーカー2枚の手札でも1回約3msです

### CPU の考え方

モックの `cpuDecide`・`cpuKeep` が基準です。強すぎず、弱すぎず、ときどき強気に出るように作っています。

- **手の強さ**：役の順位（ノーペア 0〜ファイブカード 10）に、一番強いカードの強さを少し足した値。1回目の賭けでは、4枚そろったフラッシュやストレートの候補も、ワンペア程度とみなします
- **誰も賭けていないとき**：ツーペア以上、ワンペアなら60%、それ以外も15%（はったり）でベットします。額は `200 × (1 + 強さ × 0.8) × (0.7〜1.3)` を 100単位に丸め、上限内に収めます
- **相手が賭けたとき**：
  - スリーカード以上なら50%、ツーペアなら25%でレイズします（額は「コール額」と「POT の1/3」の大きいほうに 0.6〜1.6倍をかける）。レイズしなければコールします
  - ワンペアは、コール額が自分のコインの35%未満ならコール。それ以上でも50%でコールします
  - ノーペアは、1回目の賭けなら「12%未満、または35%の確率」でコール。2回目の賭けでは、「10%未満かつ30%の確率」でだけコールし、それ以外は降ります
- **交換**：ストレート以上はそのまま。ペアがあればペア（とジョーカー）を残す。4枚そろったフラッシュ、次にストレートの候補があれば残す。それもなければ、ジョーカーと、J 以上の一番強いカードだけを残します

## 7. 実装メモ・未決事項

### 実装メモ

- **ConfirmModal との連携**：プレイ中にプラットフォームの ConfirmModal（EXIT、ロゴのクリック）が開いている間は、CPU の考え中や自動の「次のゲームへ」（4秒）を止めてください。モックではルール説明を開いている間も CPU の考え中が進むので、本実装ではそこも止めると親切です
- **キーボード操作**：すべてのボタンとカードに、水色の光のフォーカス表示を付けてください。ルール説明と ResultModal は、開いたときにフォーカスを移します
- **`prefers-reduced-motion`**：点滅、カードの移動、告知の跳ねる動きを止め、待ち時間はそのままにしてください（流れの区切りがわかるように）
- **スコアの保存**：仕様書どおり、ベストスコアなどは保存しません
- **GameItem の画像**：[temp/poker/thumbnail.png](../../temp/poker/thumbnail.png)（1280×720、PNG）をゲームデータの `image` に使ってください。置き場所は、例えば `public/images/games/poker.png` です。§8 も見てください
