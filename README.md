# neon_games

## 開発環境

- Node.js 24 以上
- 依存パッケージのインストール: `npm install`

## 主なコマンド

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバーを起動します（http://localhost:3000） |
| `npm run build` | 本番用にビルドします |
| `npm run start` | ビルドしたアプリを起動します（先に `npm run build` が必要です） |
| `npm test` | Jest でテストを実行します |
| `npm run test:watch` | ファイルの変更を監視しながらテストを実行します |
| `npm run lint` | ESLint でコードをチェックします |
| `npm run typecheck` | TypeScript の型チェックを実行します |
